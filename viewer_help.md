# Опис можливостей переглядача навчальних матеріалів 11-Д

## Що це за додаток

Переглядач призначено для зручного перегляду навчальних матеріалів курсу **11-Д**
(2026–2027 н.р.). Він показує дерево файлів зліва і вміст обраного файлу — у
фреймі справа, без необхідності встановлення додаткового програмного забезпечення
(окрім браузера).

## Як запустити

- **Після встановлення:** ярлик **📚 Viewer-for-School** — генерує (за потреби)
  сторінку і відкриває перегляд; ярлик **⚙️ Згенерувати для теки…** — створює
  `viewer.html` для іншої теки (можна просто перетягнути папку на ярлик).
- **Без встановлення:** запустіть `start_viewer.bat` — відкриється локальний
  сервер і сторінка переглядача.
- **Оновлення списку файлів:** якщо ви додали/видалили файли, натисніть
  `🔄 Оновити файли` — сторінка оновить дерево без перезапуску браузера
  (кнопка працює, коли сторінку відкрито через локальний сервер).
- **Для власного набору файлів:** `generate_for.bat "<тека>"` або
  `python generate_viewer.py "<тека>"` — створить `viewer.html` і теку
  `viewer_assets/` з прев`ю (зображення зі слайдів, PDF-експорт тощо)
  **у вибраній теці**.

## Мінімальні вимоги

- Операційна система: **Windows 10 або 11**.
- Браузер: **Microsoft Edge, Google Chrome, Firefox** (або інший сучасний
  браузер з підтримкою HTML5, localStorage, CSS-змінних).
- Для **перегляду** вже згенерованої сторінки Python **не потрібен**.
- Для **генерації** потрібен **Python 3.8+** і бібліотеки: `markdown`
  (обов'язкова), `openpyxl` і `python-pptx` (опційні, без них працюють
  фолбеки). Найпростіше: `python install_deps.py` — перевіряє й доставляє сам.
- **Опційно:** Microsoft Office — JPG-слайди `.pptx` і PDF для `.docx`;
  ffmpeg — конвертація `.avi` у `.mp4` (встановлення: `winget install Gyan.FFmpeg.Essentials`).

## Підтримувані формати і прев`ю

| Розширення | Як показується |
|-------------|-----------------|
| `.md` | Рендериться з заголовками, списками, власним форматуванням, кодом, посиланнями. |
| `.pdf` | Відкривається у фреймі (браузерний перегляд PDF). |
| `.html` / `.htm` | Відкривається у фреймі. |
| `.mp4` / `.webm` | Медіа-плеєр із перемоткою (підтримка Range). |
| `.gif`, `.jpg`, `.png`, `.webp`, `.svg` | Зображення. |
| `.pptx` | Слайди (зображення) + текст у `<details>`. |
| `.docx` | Текст із заголовками, жирністю, курсивом, таблиці, списки, посилання; є перемикач HTML ↔ PDF. |
| `.ppt` (старий PowerPoint) | Картка «Відкрити окремо» — текстовий попередній перегляд не доступний. |
| `.xlsx` | Таблиця зі збереженням форматування (шрифт, колір, заливка, межі), об`єднані клітинки. |
| `.xls` (старий Excel) | Картка «Відкрити окремо» — структура не читається без Excel. |
| `.csv` | Таблиця, рендериться як HTML-таблиця. |
| `.jar` | Картка: Java-аплікацію не можна запустити зі сторінки — відкривайте через Провідник. |
| `.avi` | За наявності ffmpeg конвертується у `.mp4` і грає у браузері; інакше — картка «Відкрити окремо». |
| Інші розширення | Картка «Відкрити окремо» — відкриває файл у програмі за замовчуванням. |

## Функції інтерфейсу

- **Дерево файлів** — папки розгортаються і згортаються, можна обрати файл.
- **Пошук** (вгорі) — фільтрує файли за назвою відразу.
- **Розділювач** між деревом і вікном перегляду — можна тягнути, щоб змінити
  ширину дерева; ширина зберігається між запусками.
- **Тема** — кнопка `🌙/☀️ Тема` змінює колір шапки, дерева і фонів самого
  переглядача (світла / темна). У темній темі зменшується навантаження на
  очі при довгому перегляді.
- **Тема в прев`ю (🎨)** — окремий перемикач, що визначає, чи будуть прев`ю
  (DOCX, Markdown, вітаюча сторінка тощо) також темними, чи залишатимуться
  світлими. За замовчуванням — «авто» (як у головній сторінці).
- **Оновити файли** — перезапускає генератор і оновлює дерево без
  перезавантаження браузера.
- **Відкрити окремо** — відкриває файл у програмі за замовчуванням
  (наприклад, PDF у зовнішньому переглядачі, .docx у Word тощо).
- **Опис** (ця сторінка) — відкривається у фреймі перегляду по кнопці `ℹ️ Опис`.

## Про темну тему в прев`ю

- У прев`ю **DOCX**, **Markdown** і **вітаючої сторінки** застосовується
  синхронізація теми: коли змінюється тема головної сторінки, прев`ю також
  змінюється (якщо обрано режим «авто» у перемикачі «Тема в прев`ю»).
- **Для XLSX таблиця завжди показується зі світлим фоном**. Це зроблено
  свідомо, бо темний фон пошкоджує читабельність таблиць із власним
  забарвленням клітинок. Стандартний вигляд файллу зберігається.
- Якщо потрібно, щоб прев`ю були темними завжди — обрати «Тема» у
  перемикачі «Тема в прев`ю». Якщо потрібно, щоб були завжди світлими —
  обрати «Світла».

## Нотатки

- Сервер працює на локальному комп`ютері (буфер `127.0.0.1`), файли не
  виходять в мережу.
- Прев`ю файлів зберігаються в теці `viewer_assets/` (зображення зі слайдів,
  PDF-експорт документів тощо). Якщо видалити її, прев`ю знову згенерується
  при наступному запуску генератора.
- Службові файли (`generate_viewer.py`, `start_viewer.bat`, `generate_for.bat`,
  `install_deps.py`, `viewer_server.*`, `viewer_probe.py`, `requirements.txt`,
  `LICENSE.txt`, `VERSION`, саме `viewer.html`) не показуються в дереві.
- Інсталятор несе лише скрипти та ярлики: матеріали, `viewer.html` і
  `viewer_assets/` **зберігаються** навіть після деінсталяції.
