# ViewerSchool 11-Д

HTML-переглядач навчальних матеріалів курсу **11-Д** (2026–2027 н.р.).

Показує дерево файлів зліва і вміст обраного файлу — у фреймі справа.
Без необхідності встановлення додаткового ПЗ (окрім браузера).

## Швидкий старт

### Варіант 1 — відкрити HTML напряму
1. Переконайтеся, що `viewer.html` існують у папці з матеріалами.
2. Відкрийте `viewer.html` у браузері.

### Варіант 2 — через локальний сервер (рекомендовано)
```bat
start_viewer.bat
```
Запустить генератор → локальний сервер → відкриє браузер.

### Варіант 3 — ручний запуск
```bat
python generate_viewer.py
python viewer_server.py --open
```

## Оновлення списку файлів

- Кнопка **🔄 Оновити файли** на сторінці (потрібен запущений сервер).
- Або: `python generate_viewer.py` у терміналі.

## Генерація для власної теки

```bat
cd "Шлях\до\папки\з\матеріалами"
python generate_viewer.py
```

Створить `viewer.html` і `viewer_assets/` з прев'ю файлів.

## Як це працює

1. **`generate_viewer.py`** сканує папку з матеріалами, витягує вміст файлів
   (pptx → JPG-слайди, docx → HTML, xlsx → таблиця, md → HTML тощо),
   генерує `viewer.html` з деревом файлів і вбудованими прев'ю.

2. **`viewer_server.py`** роздає файли на `127.0.0.1:8321` з підтримкою
   HTTP Range (перемотка відео) та CORS.

3. **`viewer.html`** — самодостатня сторінка: дерево файлів + iframe перегляду,
   пошук, темна тема, розсувний розділювач, перемикач теми прев'ю.
