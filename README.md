# Viewer-for-School

HTML-переглядач навчальних матеріалів курсу **11-Д** (2026–2027 н.р.):
дерево файлів зліва, вміст обраного файлу — у фреймі справа.

Показує PDF, Markdown, HTML, відео, зображення, а також прев'ю
`.pptx` (слайди), `.docx` (HTML/PDF), `.xlsx` (стилізована таблиця).

## Швидкий старт

### Варіант 1 — встановити (рекомендовано)

1. Запустіть `installer\Output\Viewer-for-School-Setup-<версія>.exe`.
2. Оберіть **корінь** навчальної теки (де лежать папки предметів:
   «01 Ukr mova», «07 Matematuka» тощо).
3. Залиште галочки «доставити Python-залежності» і «згенерувати viewer.html».

Ярлики: **📚 Viewer-for-School** (запуск) і **⚙️ Згенерувати для теки…**
(сторінка для іншої теки — можна перетягнути папку на ярлик).

Інсталятор сам перевіряє Python 3.8+ (за потреби встановлює з python.org
з перевіркою SHA-256), доставляє pip-залежності, попереджає про
Microsoft Office (JPG-слайди `.pptx`, PDF для `.docx`) і ffmpeg
(конвертація `.avi` → `.mp4`). Деталі — `installer/README.md`.

### Варіант 2 — без встановлення

```bat
start_viewer.bat
```

Генерує `viewer.html` → запускає локальний сервер `127.0.0.1` → відкриває браузер.

### Варіант 3 — ручний запуск

```bat
python install_deps.py           # перевірити/доставити залежності
python generate_viewer.py        # генерація viewer.html
python viewer_server.py --open   # сервер + браузер
```

> Для **перегляду** вже згенерованої `viewer.html` Python не потрібен
> (відкрийте файл у браузері або користуйтеся серверним режимом).

## Оновлення списку файлів

- Кнопка **🔄 Оновити файли** на сторінці — працює лише коли сторінку
  відкрито через «свій» сервер (перевірка `root` в `/api/status`).
- Або: `python generate_viewer.py "<тека>"`.

## Генерація для власної теки

```bat
generate_for.bat "Шлях\до\папки\з\матеріалами"
```

Або без аргументу — запропонує діалог вибору теки. Створить `viewer.html`
і `viewer_assets/` (прев'ю) **у вибраній теці**.

## Вимоги та залежності

| Компонент | Вимога |
|-----------|--------|
| ОС | Windows 10 / 11 |
| Браузер | Edge, Chrome, Firefox (HTML5, localStorage) |
| Python | 3.8+ — **тільки** для генерації |
| pip | `markdown` (обов'язкова); `openpyxl`, `python-pptx` (опційні, є фолбеки) |
| Office | опційно — JPG-слайди `.pptx` і PDF для `.docx` |
| ffmpeg | опційно — конвертація `.avi` → `.mp4` |

```bat
python install_deps.py          # єдина точка: перевіряє й доставляє
:: або вручну:
python -m pip install --user -r requirements.txt
```

## Підтримувані формати

| Розширення | Перегляд |
|------------|----------|
| `.md` | Рендеринг Markdown (заголовки, списки, код, таблиці) |
| `.pdf` | У фреймі браузера |
| `.html` / `.htm` | У фреймі |
| `.mp4` / `.webm` | Медіа-плеєр (з перемоткою, Range) |
| `.avi` | Конвертується у `.mp4` (потрібен ffmpeg), інакше — окремо |
| `.gif`, `.jpg`, `.png`, `.webp`, `.svg` | Зображення |
| `.pptx` | Слайди (JPG за наявності Office) + текст у `<details>` |
| `.docx` | HTML-рендер + перемикач HTML ↔ PDF (за наявності Office) |
| `.xlsx` | Таблиця зі стилями (шрифт, колір, заливка, межі) |
| `.csv` | Таблиця (HTML) |
| `.ppt` / `.xls` / `.jar` / інші | Картка «Відкрити окремо» |

## Як це працює

1. **`generate_viewer.py`** сканує папку з матеріалами, витягує вміст
   (pptx → слайди, docx → HTML/PDF, xlsx → таблиця, md → HTML) і генерує
   самодостатнє `viewer.html` з деревом і вбудованими прев'ю.

2. **`viewer_server.py`** роздає файли теки на `127.0.0.1:8321` (Range для
   перемотки відео), обслуговує `/api/status` і `/api/regen`; `--root <dir>`
   визначає теку матеріалів (використовується ярликом «Згенерувати для теки…»).

3. **`viewer.html`** — дерево + iframe, пошук, темна тема, розсувний
   розділювач, кнопки «🔄 Оновити файли» і «ℹ️ Опис».
